## Getting Started

---

### 1. Clone the Repository

 Clone the repository from GitHub to your device

```bash
git clone git@github.com:ADixon9/ATS.git
```

---

### 2. Create a Python Virtual Environment (Recommended)

 Open the desired location of your virtual environment by using:

```bash
cd /home/(user_name)/...
```

 Next, create the virtual environment

```bash
python3 -m venv (name_of_venv)
```

 Activate the virtual environment. Ensure you are located in the same directory as the virtual environment

```bash
source (name_of_venv)/bin/activate
```

---

### 3. Install the package and dependencies

```bash
pip install .
```

---

### 4. Run the ATS Software

 Run the ATS software by simply executing:

```bash
ats
```
